# ProcuraIQ to NetSuite Data Mapping

This document describes how core ProcuraIQ business entities map to NetSuite SuiteCloud standard and custom records. This mapping provides the blueprint for the `NetSuiteAdapter`.

## Standard Entity Mappings

| ProcuraIQ Entity | NetSuite Record | Notes / Comments |
|---|---|---|
| **Vendor** (`vendor_id`, `name`) | **Vendor** | Standard NetSuite Vendor record. |
| **Purchase Order** (`id`, `vendor`, etc.) | **Purchase Order** | Standard NetSuite PO record. |
| **Procurement Request** (`category`, `qty`) | **Purchase Requisition** | NetSuite's built-in Requisition flow. |
| **PO Line Item** (`item_id`, `unit_price`) | **InventoryItem** / **NonInventoryItem** | Depending on whether physical stock is tracked. |

## Field-Level Mapping (Purchase Order)

**ProcuraIQ JSON (Example)**
```json
{
  "purchase_order_id": "PO-1234",
  "vendor_id": "V-5678",
  "item_id": "ITM-90",
  "quantity": 100,
  "unit_price": 50.0
}
```

**NetSuite Internal Field Mapping**
- `entity.id` <- `vendor_id`
- `item.items.item.id` <- `item_id`
- `item.items.quantity` <- `quantity`
- `item.items.rate` <- `unit_price`
- `memo` <- `"Generated by ProcuraIQ Automation"`

## Future Extension (Custom Records)

To fully synchronize ProcuraIQ's ML and Scoring engines, the following Custom Records may need to be deployed in the SuiteCloud project in the future:
1. `customrecord_procuraiq_vendor_score`: To sync ML-predicted risk and quality scores per vendor into NetSuite dashboards.
2. `customrecord_procuraiq_po_evaluation`: To sync the AI Procurement Decision attached to a specific Purchase Order.
